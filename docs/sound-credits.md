# Nguồn âm thanh

Các file trong `apps/web/public/audio/sfx/` lấy từ thư viện Woven SFX (CC0, không cần ghi công), đã cắt ngắn và đưa về mono 22,05 kHz, qua
thư viện âm thanh của Alo Khách Ơi (ADR-023 của Alo).

| File                    | Dùng cho                            |
| ----------------------- | ------------------------------------ |
| `mouse-click-2.wav`     | Bấm nút                              |
| `tick.wav`              | Gõ chữ khi hội thoại, gõ phím         |
| `pop-hand.wav`          | Chọn một lựa chọn                    |
| `message-pop-reply.wav` | Tám với đồng nghiệp                  |
| `notification-ding.wav` | Tiếng "ting" của ngân hàng           |
| `several-coins.wav`     | Có tiền                              |
| `money-chalking.wav`    | Vay nợ                               |
| `fast-whoosh.wav`       | Sang chương mới                      |
| `dull-thud.wav`         | Bỏ đi, khủng hoảng                   |

Nhạc nền và các tiếng còn lại được tổng hợp trong trình duyệt, không có file.
