# Test Command

Run and document tests for the current task.

## Steps

1. Read the task documentation.
2. Read `test.md`.
3. Identify all test scenarios.
4. Run automated tests where available.
5. Perform required manual tests.
6. Record results.

For every scenario record:

- ID
- scenario
- expected result
- actual result
- status
- notes

Use:

PASS
FAIL
BLOCKED
NOT TESTED

If a test fails:

Do not mark the task complete.

Investigate or return the task to implementation.
