# Status Command

Give a concise development status.

Read:

- `.project/CURRENT.md`
- active tasks
- blocked tasks
- recently completed tasks

Return:

## Current Task

Task ID and title.

## Status

PLANNING
IMPLEMENTING
TESTING
BLOCKED
REVIEW
COMPLETED

## Progress

Completed steps.

## Current Problem

Current blocker or issue.

## Next Step

The next concrete development action.

## Recent Tasks

Recently completed tasks.

Do not modify code.
Do not modify task state.
